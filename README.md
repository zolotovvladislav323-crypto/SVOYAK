# Мой VPN (My VPN)

**Мой VPN** — это минималистичный, но мощный VPN-клиент для Android, построенный на базе ядра Xray/V2Ray. Приложение разработано для простого и надёжного обхода интернет-ограничений. Оно идеально подходит как для новичков, так и для продвинутых пользователей благодаря интуитивному интерфейсу и гибким настройкам.

Проект основан на открытом коде [v2whitelist (ПроБел)](https://github.com/NullCoreDeveloper/v2whitelist) и распространяется под лицензией **GPL-3.0**.

---

## 📱 Основные возможности

- **Подключение в один клик** — большая кнопка «Старт» на главном экране.
- **Автоматический выбор серверов** — встроенные списки с поддержкой обновления (OTA).
- **Фильтр по странам** — выбор географических локаций для маршрутизации трафика.
- **Импорт конфигураций** — через QR-код, URL или вручную.
- **Поддержка подписок** — управление несколькими источниками серверов.
- **Режим прокси** — работа без VPN-интерфейса (только прокси).
- **Виджет и плитка быстрых настроек** — управление VPN прямо с рабочего стола.
- **Автозапуск после перезагрузки** — опционально.
- **Интеграция с Tasker** — автоматизация сценариев.
- **Полная поддержка Android 7+ (API 24)** и новейших версий.

## 🛠 Сборка проекта

### Требования
- **Android Studio** (рекомендуется последняя версия)
- **JDK 17** или новее
- **Android SDK** с установленными компонентами:
  - Платформа Android 13+ (API 33+)
  - NDK (версия 28.2.13676358 или совместимая)
- **Git** (для клонирования)

### Шаги сборки

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
   cd YOUR_REPO
   ```

2. **Откройте проект в Android Studio** или соберите через командную строку:
   ```bash
   ./gradlew assembleRelease
   ```
   Готовые APK будут находиться в `app/build/outputs/apk/`.

### Автоматическая сборка через GitHub Actions
В репозитории настроен **GitHub Actions workflow** (`.github/workflows/release.yml`). При создании тега вида `v*` (например, `v1.0.0`) запустится автоматическая сборка, подписание APK и создание релиза с загруженными артефактами.

Для работы подписи необходимо добавить следующие секреты в настройках репозитория (`Settings → Secrets and variables → Actions`):
- `RELEASE_KEYSTORE` — содержимое keystore-файла в кодировке **Base64** (получить можно командой `base64 -w 0 release.keystore`).
- `RELEASE_KEYSTORE_PASSWORD` — пароль хранилища.
- `RELEASE_KEY_ALIAS` — псевдоним ключа.
- `RELEASE_KEY_PASSWORD` — пароль ключа.

## ⚙️ Настройка приложения

Приложение не требует сложной конфигурации. После установки:

1. **Разрешите приложению** запрашиваемые права (VPN, уведомления, доступ к камере для сканера).
2. **Нажмите «Старт»** на главном экране — VPN подключится к случайному серверу из встроенного списка.
3. Для выбора конкретной страны перейдите в **Настройки → Фильтр локаций**.
4. Чтобы добавить свой сервер, используйте **QR-сканер** или вручную введите ссылку в формате `vless://...` в разделе **Подписки**.

## 🧩 Интеграция с Tasker

Приложение поддерживает плагин для **Tasker** (и аналоги). Вы можете управлять VPN-соединением через действия:
- `com.yourcompany.myvpn.action.START` — запустить VPN.
- `com.yourcompany.myvpn.action.STOP` — остановить VPN.

В Tasker создайте новое действие → **Плагин** → выберите **Мой VPN** и настройте нужное действие.
